# CryptoQuest — Encryption & Decryption CTF

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser (Chrome, Firefox, Safari, or Edge).
3. No installation, server, API key, or internet connection is required.

## Included
- 10 progressive classroom CTF challenges
- Flag submission and level unlocking
- XP and hint counters
- Three hints per challenge and a walkthrough
- Cryptography field guide: basics, classical ciphers, modern crypto, tools and safety
- Responsive layout for desktop and mobile

## Important limitation
This is a client-side educational prototype. Challenge answers and validation logic are present in `index.html`, so students can inspect the source to find answers. For a graded or competitive CTF, move flag validation to a backend and add per-student sessions/progress tracking.
